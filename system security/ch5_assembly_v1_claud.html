강의 기준 모델: 80386

  • 1985년 생산, 내부·외부 데이터 버스와 주소 버스가 모두 32비트 — 표에서 처음으로 32비트가 등장하는 모델.
  • 데이터 크기 8, 16, 32비트를 모두 다룸 → 이후의 레지스터 체계(AL/AX/EAX)의 기준이 됨.

명령어(Instruction) 실행 — Fetch and Execution Cycle

Slide 4
  1. Fetch — PC가 가리키는 메모리 위치의 명령어(0000001111000011)를 읽어 IR에 적재
  2. Decode — IR에 담긴 명령을 해독
  3. Fetch operands — 연산에 필요한 피연산자를 메모리에서 read하여 레지스터로
  4. Execute — ALU가 레지스터 값으로 연산 수행, 결과에 따라 flags 갱신
  5. Store output — 결과를 레지스터 또는 메모리에 write

연산장치(ALU) · 제어장치(CU)

Slide 5–6

연산장치 (Arithmetic and Logic Unit)

CPU의 핵심 부분 중 하나로, 산술과 논리 연산을 수행하는 연산 회로 집합으로 구성.

구성 요소기능
가산기 (Adder)덧셈 연산 수행
보수기 (Complementer)뺄셈 연산 수행. 1의 보수나 2의 보수 방식 이용
시프터 (Shifter)비트를 오른쪽이나 왼쪽으로 이동하여 나눗셈과 곱셈 연산 수행

제어장치 (Control Unit)

입력·출력·기억·연산 장치를 제어하고 감시, 주기억 장치에 저장된 명령을 차례로 해독하여 연산 장치로 보내 처리되도록 지시.

구성 요소기능
명령 해독기 (Instruction Decoder)명령 레지스터에 있는 명령을 해독하여 부호기로 전송
부호기 (Decoder)명령 해독기가 전송한 명령을 신호로 만들어 각 장치 전송
주소 해독기 (Address Decoder)명령 레지스터에 있는 주소를 해독하여 메모리의 실제주소로 변환한 후, 이를 데이터 레지스터에 저장
흐름: 명령 해독기 → 부호기 → 각 장치 (명령 처리) / 주소 해독기 → 실제 메모리 주소 → 데이터 레지스터 (주소 처리)

07

메모리의 기본 구조

Slide 12–14

스택 (Stack)

  • 함수의 리턴 주소, 호출된 함수 내의 로컬변수 등이 저장
  • 상위주소 → 하위주소 방향으로 증가
  • EBP: 현재 호출되어 사용되는 함수의 시작 주소
  • ESP: 스택의 가장 상단, 즉 현재 스택 영역에서 가장 하위 주소

힙 (Heap)

  • 프로그램 실행 중 필요한 기억 장소를 할당하기 위해 운영체제에 예약되어 있는 기억 장소 영역
  • new나 malloc()으로 동적 메모리 할당 시 사용 — 예: char *p = new char[1000];

데이터 세그먼트

  • 초기화된 데이터 세그먼트 (initialized data segment)
  • 초기화된 외부 변수나 static 변수 등이 저장 — 예: static int a=1;
  • 보통 텍스트 세그먼트와 데이터 세그먼트 영역을 합쳐 프로그램이라 한다

BSS (Block Started by Symbol) 세그먼트

  • 초기화되지 않은 데이터 세그먼트 (uninitialized data segment)
  • 프로그램이 실행될 때 0이나 NULL 포인터로 초기화
  • 외부 변수나 static 변수 중 초기화되지 않은 변수 저장 — 예: static int a;

텍스트 세그먼트

  • CPU에 의해 실행되는 머신 코드가 있는 영역, 코드 세그먼트라고도 함
  • EIP (Extended Instruction Pointer): 다음에 실행하는 명령의 주소값 저장. 예전에 PC(Program Counter)라고 부르기도 함
비교Data SegmentBSS Segment
초기화 여부초기화된 데이터초기화되지 않은 데이터 (실행 시 0/NULL)
예시static int a=1;static int a;

메모리 주소 연산: 음수 표현과 2의 보수

Slide 15

음수 표현 방법은 세 가지 (MSB: most significant bit).

방법규칙−3 (8bit)
부호화 절대값양수면 MSB 0, 음수면 MSB 11000 0011
1의 보수0은 1로, 1은 0으로 변환1111 1100
2의 보수1의 보수에 1을 더함1111 1101
+3 = 0000 0011 → 비트 반전 1111 1100 → +1 → 1111 1101 = −3 (2의 보수)

ALU의 보수기가 이 방식으로 뺄셈을 수행하며(섹션 04), NEG 명령은 피연산자의 2의 보수를 구한다(섹션 14).

어셈블리어 Slide 17

  • 어셈블리어: 기계어의 비트 형식을 니모닉 코드(mnemonic code)로 나타낸 것
  • 니모닉 코드: 기계어의 비트 형식이 나타내는 의미를 심벌(symbol)로 표현한 것으로 프로그램을 이해하거나 작성하기가 쉽다. 예: MOV A, #03H
어셈블리어로 프로그래밍을 하는 이유
① 컴퓨터 하드웨어의 구성 요소들을 직접 액세스하려고 할 때
② 컴파일러를 설계하거나 시스템 프로그램을 작성하려고 할 때
③ 빠른 수행이 필요한 프로그램을 작성하려고 할 때
④ 기억 장소를 적게 차지하거나 입출력 장치를 보다 효율적으로 사용하려는 경우

점프할 주소 또는 라벨로 이동. 형식: JMP [제1피연산자]

JMP   100h             ; 주소로 직접 지정한 100h번지로 점프
label:  MOV   ECX, 30
        ...
        JMP   label    ; 라벨로 JMP를 지정하는 경우

⚠ 슬라이드 표 안의 불일치 — 같은 슬라이드의 ‘점프 조건’ 열과 하단 주석을 기준으로 읽으면:
• JG/JNLE · JLE/JNG: greater/less 계열이므로 부호화된 수 비교 (설명 칸의 “부호화 안된 수”와 어긋남)
• JNP/JPO: 조건이 PF = 0 → PF가 0이면 점프
• JNS: 조건이 SF = 0 → SF가 0이면 점프
시험 대비 시 담당 교수님 의도를 확인해 두는 것을 권장.

CALL / RET Slide 53

  • CALL: 제1피연산자에 라벨을 지정, 리턴 주소로 EIP 백업 — ‘PUSH EIP + JMP’와 같은 의미
  • RET (Return from CALL): 호출한 곳으로 돌아갈 때 사용 — ‘POP EIP’와 같은 의미
        MOV   EAX, 0x09
        CALL  SUBR
        ADD   EAX, 0x10
        ...
SUBR :  INC   EAX
        ....
        RET

LOOP (Loop ECX times) Slide 54

문장들의 블록을 지정된 횟수만큼 반복. ECX는 자동적으로 카운터로 사용되며 루프 반복할 때마다 감소.

        MOV   EAX, 0
        MOV   ECX, 5
L1 :    INC   AX
        LOOP  L1

제1피연산자는 라벨. L1이 ECX의 숫자만큼 5번 회전하므로 결과적으로 EAX는 5가 된다.

INT (Interrupt)

인터럽트가 호출되면 EIP와 플래그를 스택에 저장, 해당 인터럽트에 관련된 서브 루틴이 실행. 형식: INT [제1피연산자]

핵심 요약

Ch 5 전체

01–04CPU 구조

  • 80386: 데이터·주소 버스 32비트, 물리 메모리 4G
  • CPU = ALU + CU + Register + BUS 인터페이스
  • 실행 사이클: Fetch → Decode → Fetch operands → Execute → Store
  • ALU = 가산기·보수기·시프터 / CU = 명령 해독기·부호기·주소 해독기

05–06레지스터

  • EAX(누산기, 리턴값) · EBX(베이스) · ECX(카운트, 루프) · EDX(데이터)
  • EBP(스택 내 변수) · ESP(스택 끝) · EIP(다음 명령 주소 = PC)
  • ESI(출발지) · EDI(목적지) / CS·DS·SS·ES·FS·GS 16비트
  • EFLAGS 상태 플래그: CF(0) PF(2) AF(4) ZF(6) SF(7) OF(11)

07메모리 구조

  • 상위: Stack ↓ … ↑ Heap · Data · BSS · Text :하위
  • Stack은 하위 주소 방향으로 증가 (ESP = 가장 하위 주소)
  • Data = 초기화된 static/외부 변수, BSS = 미초기화(0/NULL)
  • Heap = new/malloc 동적 할당, Text = 머신 코드(EIP)

08–10데이터 표현

  • 2의 보수 = 1의 보수 + 1 (−3 = 1111 1101)
  • CPU는 기계어만 이해 → 어셈블러가 변환
  • Byte 8 · Word 16 · Doubleword 32 비트
  • Intel = 리틀 엔디안 (LSB를 작은 번지에)

11–13문법 · 인코딩

  • Intel: op dest, src / AT&T: op src, dest, $·%·접미사
  • 주소 지정: Register(가장 빠름) · Direct · Reg Indirect · Index · Base-Index(+Disp)
  • 형식: Prefix · Opcode · ModR/M · SIB · Disp · Imm
  • ADD EAX,EBX = 03 C3 (Mod 11, Reg 000, R/M 011)

14–19명령어 세트

  • CMP = SUB(저장 X) / TEST = AND(저장 X), 둘 다 ZF 반영
  • MOV = 값 / LEA = 주소, PUSH: ESP↓ / POP: ESP↑
  • DIV: 몫 EAX, 나머지 EDX / REP·LOOP는 ECX 카운터
  • CALL = PUSH EIP + JMP, RET = POP EIP
