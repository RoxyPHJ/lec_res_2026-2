01

패킷 큐잉과 손실

1.4 · 슬라이드 2

패킷은 라우터 버퍼에 큐잉된다

  • 패킷 도착율이 링크 출력용량을 초과할 때 패킷은 버퍼에 쌓인다.
  • 버퍼에 큐잉된 패킷은 자기 순서를 기다린다 → 지연
  • 현재 링크로 나가고 있는 패킷도 전송 시간을 소비 → 지연
  • 빈(available) 버퍼가 없으면 새로 도착한 패킷은 폐기된다 → 손실
즉, 지연(delay)과 손실(loss)의 공통 원인은 출력 링크 앞의 버퍼(큐)이다.
02

패킷지연의 4가지 유형

슬라이드 3

한 노드에서 발생하는 네 가지 지연

  • ① 노드처리 비트 오류 검사, 출력 링크 결정
  • ② 큐잉 출력 링크에서 전송을 기다리는 시간 — 라우터의 혼잡 정도에 좌우
  • ③ 전송 패킷의 모든 비트를 링크로 내보내는 시간 = L/R
  • ④ 전파 비트가 물리 링크를 따라 이동하는 시간 = d/s

지연 유형 비교

유형무엇에 쓰이는 시간인가결정 요인식
① 노드처리check bit errors, determine output link라우터 처리—
② 큐잉출력 링크에서 전송 대기라우터 혼잡도 (congestion level)La/R 에 따라 변화 (03 참고)
③ 전송비트들을 링크로 밀어내는 시간R = 링크 대역폭(bps), L = 패킷 길이(bits)L / R
④ 전파링크 위를 비트가 이동하는 시간d = 물리 링크 길이, s = 매체 내 전파속도(~2×108 m/s)d / s
③ 전송 vs ④ 전파: 전송지연은 패킷 길이와 대역폭에만 의존하고 거리와 무관하다. 전파지연은 링크 길이와 전파속도에만 의존하고 패킷 길이와 무관하다.

전송지연 · 전파지연 계산기

슬라이드 3의 두 공식 L/R, d/s를 그대로 적용합니다. (값을 바꾸면 즉시 계산 — JS 미지원 환경에서는 기본값 결과가 표시됩니다)

03

큐잉지연과 트래픽 강도

슬라이드 4

트래픽 강도 (traffic intensity)

  • R: 링크 대역폭 (bps)
  • L: 패킷 길이 (bits)
  • a: 패킷 도착률
traffic intensity = La / R
  • La/R = 0 : 큐잉지연이 없음 (한산한 도로)
  • La/R 값이 1로 접근 : 지연이 점차 커짐 (정체된 도로)
  • La/R > 1 : 지연이 무한대로 발산
La/R = 0.50 → 지연이 점차 커지는 구간
La는 초당 도착하는 비트 수(bits/s), R은 초당 내보낼 수 있는 비트 수(bps)이므로 La/R은 "들어오는 양 ÷ 나갈 수 있는 양"이다. 1을 넘으면 큐가 끝없이 길어진다.

프로토콜 계층과 서비스 모델

1.5 · 슬라이드 6
  • 인터넷은 매우 복잡한 시스템 → 항공기 여행과정의 예처럼 단계별로 나누어 이해
  • 프로토콜을 계층(layer)으로 조직
  • 서비스 모델: 한 계층이 상위 계층으로 제공하는 서비스
  • 프로토콜 스택: 인터넷 — 애플리케이션, 트랜스포트, 네트워크, 링크, 물리 계층 (5계층) / OSI 7계층

프로토콜 계층화의 장점 vs 단점

장점단점
시스템 구성요소의 갱신을 용이하게 함한 계층의 기능이 하위 계층과 중복됨
한 계층에서 타 계층의 정보가 필요한 경우 발생

인터넷 프로토콜 스택

슬라이드 7
계층역할대표 프로토콜
application네트워크 애플리케이션 지원FTP, SMTP, HTTP, IMAP
transport프로세스와 프로세스 간 데이터 전달TCP, UDP
network출발지와 목적지 간 데이터그램 라우팅IP, routing protocols
link이웃 노드 간 데이터 프레임 이동PPP, Ethernet
physical프레임 내부 각 비트의 노드 간 이동—
transport vs network: transport는 프로세스 ↔ 프로세스(종단 호스트 내부의 프로그램 간), network는 출발지 호스트 ↔ 목적지 호스트 간 라우팅. link는 그 경로 중 이웃 노드 한 구간만 담당.

08

공격받는 네트워크

1.6 · 슬라이드 9–11

Denial of Service (DoS)

네트워크, 호스트 혹은 다른 기반구조의 요소들을 정상적인 사용자들이 사용할 수 없게 하는 것.

  1. select target — 공격 대상 선정
  2. break into hosts around the network — 네트워크 곳곳의 호스트에 침입
  3. send packets toward target from compromised hosts — 감염된 호스트들이 대상에게 패킷 전송

Packet sniffing

  • broadcast media (shared Ethernet, wireless) 환경
  • 지나가는 모든 패킷의 사본을 기록하는 수동적인 수신자
  • B → A 로 가는 패킷을 C가 복사해 본다

IP spoofing

  • 위장된 소스 어드레스로 전송
  • 신뢰하는 사람인 것처럼 위장
  • C가 보낸 패킷인데 src:B로 적혀 있어 A는 B가 보낸 것으로 인식

세 가지 공격 비교

공격슬라이드 정의공격 방식
DoS정상적인 사용자들이 네트워크·호스트·기반구조를 사용할 수 없게 함select target → break into hosts → 감염된 호스트들이 target으로 패킷 전송
Packet sniffing지나가는 모든 패킷의 사본을 기록하는 수동적인 수신자broadcast media(shared Ethernet, wireless)에서 B→A 패킷을 C가 기록
IP spoofing위장된 소스 어드레스로 전송C가 src:B로 위장 → A는 신뢰하는 B로 인식
09

인터넷 역사

1.7 · 슬라이드 12–15

1961–1972 · Early packet-switching principles

  • 1961 Kleinrock — 큐잉 이론으로 패킷교환의 효율성 입증
  • 1964 Baran — 군사 네트워크의 패킷교환
  • 1967 ARPA가 ARPAnet 구상 · 1969 첫 ARPAnet 노드 가동
  • 1972 ARPAnet 공개 시연, NCP(최초 host-host 프로토콜), 첫 e-mail, 15 nodes

1972–1980 · 독점 네트워크와 인터네트워크

  • 1970~ ALOHAnet 위성 네트워크(하와이)
  • 1974 Cerf & Kahn — 네트워크 상호연결 구조
  • 1976 이더넷 프로토콜(맷칼프와 보그스) · 1979 ARPAnet 200 nodes

1980–1990 · 네트워크 확산

  • 1982 SMTP · 1983 TCP/IP 배치, DNS 정의 · 1985 FTP
  • 1988 TCP 혼잡제어 · 100,000 hosts

1990, 2000's · 인터넷 급증

  • Early 1990's ARPAnet → MILNET, NSFnet · 1991 NSFnet 상용화
  • early 1990s Web: hypertext, HTML·HTTP(Berners-Lee), 1994 Mosaic→Netscape
  • late 1990's–2000's 메신저·P2P, 보안 부각, 5천만 host, Gbps 백본

2005 – present

  • ~18B devices (2017), 스마트폰(iPhone 2007), 광대역·4G/5G/WiFi
  • SNS(Facebook ~2.5B), 서비스 제공자 자체 네트워크, 클라우드(AWS, Azure)
  • New services: AI 기반 IoT, cloud computing, blockchain
10

핵심 요약

전체

01큐잉과 손실

도착율 > 출력용량 → 버퍼 큐잉(지연). 버퍼가 가득 차면 도착 패킷 폐기(손실).

024가지 지연

노드처리 · 큐잉 · 전송(L/R) · 전파(d/s). 전송은 거리 무관, 전파는 패킷 길이 무관.

03트래픽 강도

La/R ≈ 0 지연 없음, → 1 급증, > 1 발산.

04tracert

홉별 3회 측정. 대양 횡단 링크에서 지연 급증, * = 무응답.

05계층화

서비스 모델 = 상위 계층에 제공하는 서비스. 장점: 갱신 용이 / 단점: 기능 중복, 타 계층 정보 필요.

065계층 스택

application · transport(프로세스 간) · network(호스트 간 라우팅) · link(이웃 노드 간) · physical(비트).

07캡슐화

message → segment(Ht) → datagram(Hn) → frame(Hl). 스위치 2계층, 라우터 3계층까지 처리.

08공격

DoS(감염 호스트로 폭주) · Sniffing(수동적 사본 기록) · Spoofing(출발지 위장).

09역사

패킷교환 원리(1961–72) → 인터네트워킹(72–80) → TCP/IP·DNS(80–90) → Web(90s) → 모바일·클라우드(2005~).
